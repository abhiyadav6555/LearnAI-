# 🎓 LearnAI - E-Learning Platform

LearnAI is a full-stack E-Learning Platform built using the MERN Stack.

It allows students to discover courses, enroll in courses, learn through
lessons, track their learning progress, and allows instructors to create
and manage educational content.

---

# 🚀 Features

## 👨‍🎓 Student Features

- Student Registration & Login
- Browse Courses
- View Course Details
- Enroll in Courses
- Start Lessons
- Complete Lessons
- Track Course Progress
- View Completed Lessons
- Learning Progress Percentage
- Student Dashboard
- Continue Learning
- My Learning Courses

---

## 👨‍🏫 Instructor Features

- Instructor Registration & Login
- Instructor Dashboard
- Create New Course
- Add Course Lessons
- View Created Courses
- Course Management
- Manage Course Content
